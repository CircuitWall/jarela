# 2026-05-16 — Day 2

Yesterday I had the walls up. Today I tried to actually live inside it,
and that turned out to mean **44 commits** of "oh, this part isn't real
yet."

The big one was tools. The agent could chat, but it couldn't *do*
anything — no files, no images, no follow-through. By the end of today
it has a real toolkit and a real stop button, and it doesn't lie to me
about being "right on it."

## What landed

### A real file toolkit

I went through it piece by piece — `file_read`, `file_write`,
`file_edit`, then `file_move`, `file_list`, `file_mkdir`, then a
sectioned permission UI on top so I can grant filesystem access per
agent without it becoming an all-or-nothing switch. A couple of follow-up
fixes the same day:

- `file_list` now returns full results by default (I had it paginated and
  the agent kept tripping over it).
- Relative paths resolve against `HOME`, not the Next.js cwd. Otherwise
  the agent thinks "my notes" lives inside `.next/`.
- Cap result sizes on `file_list` / `file_read` so one accidental
  `~/Downloads` listing doesn't blow up the context.

### Images, properly

Added `generate_image` backed by Gemini/Imagen. Then immediately spent
two commits cleaning up image *handling* on the GitHub Copilot adapter —
it was happily inlining base64 payloads into the compact transcript,
which meant every conversation rotted itself after one image.
Now the compact step summarizes **before** clearing, the github-copilot
adapter keeps its vision header and image-content transform, and the
transcript stays readable.

### Stop. Actually stop.

The Stop button was a lie. It just hid the streaming bubble while the
server kept running. Now it aborts the server-side agent run for real.
While I was in there: Enter queues a message while a turn is in flight,
and the queue drains as **one** agent turn instead of N back-to-back
turns. That alone made the thing feel twice as fast.

### Don't promise, do

Two agent-side fixes that took a lot of attempts to get right:

- Detect "give me a moment" / "one second" stalls inline and **mark**
  them, so the agent doesn't think it already replied.
- Auto-retry stalled turns with a forceful nudge — basically "you said
  you'd do X, do X now, no preamble."
- Raised default `recursionLimit` from 50 → 200 so longer multi-tool
  turns don't get guillotined mid-thought.

### Mobile + PWA hardening

This is where I lost the most hours.

- Respect Dynamic Island / notch safe-area-inset on the top header.
- Keep a 12px bottom padding on the input bar when safe-area inset is 0
  (so it doesn't kiss the bottom of the screen on Android).
- Migrate next-pwa → **Serwist** (next-pwa is unmaintained against Next
  16 + React 19).
- Switch the service worker to pathname-based matchers and purge stale
  WS cache on activate. The old SW was caching `ws://` upgrade requests.
  That's about as wrong as it sounds.
- Two Safari-PWA bugs: empty agent list on first load, and a slow
  startup that turned out to be a synchronous DB read on the critical
  path.

### Streaming that survives a pocket

The single most-tested commit of the day:
**fix(streaming): survive mobile WS drop by reattaching to run via SSE.**

The flow: client subscribes via WS → screen sleeps → iOS kills the
socket → client wakes up → instead of restarting the turn from scratch,
it reattaches to the in-flight run over SSE and resumes the token
stream. Two related fixes had to land first: mark `ws` as a
`serverExternalPackage` so Next doesn't try to bundle `bufferutil` (and
crash at runtime), and proxy WS through the tailscale-served path with
a tighter access check.

### Notifications that don't double-fire

- Persist `lastTs` across reloads so reopening doesn't replay the last
  N hours of toasts.
- Reconnect SSE on `visibilitychange` (not just `online`).
- Prefer the OS notification when the page is hidden; suppress the
  in-app toast in that case. Otherwise I'd get the same message twice on
  the lock screen and in the tab.
- Scheduler gets a **Run-now** button + an agent icon in the
  notification body so I can tell at a glance which one fired.

### The big dep bump

React 19, Zod 4, OpenAI 6, Next 16, Tailwind 4, ESLint flat config, all
in one afternoon. Mostly painless. ESLint flat config ate twenty
minutes — I had `import` rules in the old format and the new one is

## What I learned

- **The agent will lie about being busy if you let it.** "Give me a
  moment" / "one second" is a stall, not a status. Detect it, mark it,
  retry with a nudge. Don't trust polite language.
- **Caps everywhere.** `file_list`, `file_read`, image payloads,
  compact transcripts. Every tool that returns "a list of stuff" needs
  a default cap, or one bad call eats the context window.
- **Mobile WebSocket lifetime is not what you think.** iOS will kill
  the socket the moment the screen sleeps. Plan reconnection as a
  first-class feature, not an error path. The SSE reattach path is
  not optional.
- **Service workers cache more than you tell them to.** I had a stale
  WS upgrade response cached for hours. Always purge on activate when
  the matchers change.
- **PowerShell 5.1 `Set-Content -Encoding utf8` writes a BOM.** Five
  of today's commits have `´╗┐` in front of the subject because I
  scripted commit messages with `Set-Content`. The BOM is invisible in
  `git log --oneline` and shows up as `´╗┐` in `git log --format='%s'`.
  Use `[System.IO.File]::WriteAllText($p, $s, (New-Object
  System.Text.UTF8Encoding $false))`. I'll leave the BOM'd commits as a
  monument; rewriting them isn't worth the rebase.
